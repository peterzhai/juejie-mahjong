# Cocos 客户端启动入口

新增 ClientBootstrap 组件，程序化创建大厅、玩法设置、牌桌与返回入口，替代逐个绑定 Inspector 属性。设置支持牌张方案与 AI 难度，并保存至本地。

## 启动

1. 使用已安装的 Cocos Creator 创建 Empty 2D 工程，设计尺寸 1280 × 720。
2. 将 assets/scripts 拷入工程；按 README 的 npm 依赖方案引入两个共享规则包。
3. 在入口场景 Canvas 上挂 ClientBootstrap，保存场景并设为启动场景。
4. 预览后点击单机对局。此入口通过同场景视图切换工作，无需额外建立 Lobby/Table 场景。
